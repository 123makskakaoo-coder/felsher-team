# Felsher Team

Статическая визитка команды по Counter-Strike 2. Без сборки и зависимостей — просто файлы, которые GitHub Pages отдаёт как есть.

## Как запустить локально

Открой `index.html` двойным кликом. Сервер не нужен.

## Что править

Всё содержимое команды живёт в [`team-data.js`](team-data.js):

- `info` — игра, регион, год, время созвонов. Пустая строка скрывает плашку.
- `roster` — состав. Раскомментируй строку и впиши ник с ролью, карточка появится сама.
- `links` — Discord, Telegram, Steam, Faceit, YouTube, TikTok. Раздел «Контакты» показывается только когда хотя бы одна ссылка заполнена.
- `join` — раздел «Набор». Показывает `open: true`, текст — в `text`.

Тексты «О команде» и обложка — в `index.html`. Логотип — `assets/felsher-logo.jpg`.

## Публикация

Пуш в ветку `main` обновляет сайт автоматически: GitHub Pages включён с корня репозитория.
